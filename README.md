# Grilles du soir

Dix jeux : casse-têtes de logique (Reines, Soleil & Lune, Fil, Patchwork, Sudoku, Nonogramme, Futoshiki, Flux, Lumières) et mots fléchés en français, 150 niveaux chacun, défis du jour et badges.

**Jouer :** https://liodesmecht-wq.github.io/grilles-du-soir/

## Installer sur le téléphone
- **iPhone (Safari)** : Partager › « Sur l'écran d'accueil ».
- **Android (Chrome)** : menu ⋮ › « Installer l'application ».

Après la première ouverture, l'appli fonctionne hors ligne. La progression reste sur l'appareil ; *Réglages › Transférer* permet de la copier vers un autre appareil.

## Mettre à jour
Remplacer `index.html`, puis augmenter le numéro `CACHE` dans `sw.js` (ex. `grilles-v2`) pour que les téléphones reçoivent la nouvelle version.
